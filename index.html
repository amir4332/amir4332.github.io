Ash Studio

The private publishing tool of the YouTube channel Ash Holds On.

What it is

Ash Holds On is a YouTube channel of animated survival stories. Ash Studio is the small tool its owner uses to manage that one channel: it sets the title, description, tags and thumbnail of the channel's own videos, and reads the channel's own statistics (views, watch time, audience retention) to plan the next video.

Who can use it

Only the owner of the Ash Holds On channel. Ash Studio is not offered to the public, has no sign-up, and does not access any other person's account or channel.

Google and YouTube data

Ash Studio signs in with Google OAuth and uses the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API, only for the owner's own channel. Read the Privacy Policy for exactly what is accessed and how it is handled.
