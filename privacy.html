Privacy Policy

Ash Studio · effective November 19, 2026

Ash Studio is a private tool used only by the owner of the YouTube channel Ash Holds On to manage that channel. It has no other users. This page explains what Google and YouTube data it accesses and what it does with it.

YouTube API Services

Ash Studio uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

With the owner's permission, given through Google sign-in, Ash Studio accesses only the owner's own channel:

  • the channel's videos and their metadata: title, description, tags, thumbnail, category and privacy setting;
  • comments on the channel's own videos;
  • the channel's YouTube Analytics and Reporting data: views, watch time, audience retention, impressions and click-through rate.

It requests the scopes youtube, youtube.force-ssl and yt-analytics.readonly for this purpose only.

How the data is used

  • To update the metadata and thumbnails of the owner's own videos, only when the owner asks.
  • To read the owner's own channel statistics, so the owner can plan new videos.

The data is not sold, not shared with third parties, not used for advertising, and not combined with data from any other person.

Storage and security

The sign-in credentials are kept in a private configuration that only the owner can access, and are never published. Short summaries of the channel's own statistics may be kept in the owner's private notes. Ash Studio does not collect or store data about viewers or any other users.

Removing access and data

The owner can remove Ash Studio's access at any time in the Google account's third-party access settings (also at security.google.com/settings/security/permissions). After access is removed, Ash Studio can no longer read or change anything. The stored credentials and statistics notes are deleted when the owner stops using the tool.

Changes

If this policy changes, the new version is posted on this page with a new effective date.

Contact

Questions about this policy can be sent to the support email shown on Ash Studio's Google sign-in screen.
